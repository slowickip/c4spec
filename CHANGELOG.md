# Changelog

## 0.1.0-alpha.3

- Build direct and native review packets on Node.js 22, 24 and 26.
- Download diagram changes from GitHub Actions for pull requests from forks.
  Same-repository pull requests also show the visual comment.
- Build an installable CLI tarball with `npm pack`. It includes the consumer
  guide, reference workflow and license notices.
- Use the default basic profile for diagram maintenance. Install the
  experimental model-first workflow with the extended profile.
